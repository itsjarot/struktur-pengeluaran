# Struktur Keuangan

Dokumentasi sistem kategorisasi pengeluaran pribadi — berbasis Obsidian.

## Tentang Proyek

Proyek ini bukan aplikasi atau catatan transaksi harian. Ini adalah **dokumentasi sistem** — seperangkat aturan, definisi, dan alur berpikir untuk mengelompokkan pengeluaran ke dalam kategori yang konsisten dan mudah dipahami.

Tujuannya sederhana: **kalau ada transaksi baru, kamu langsung tahu masuk "gerbong" mana**.

## Ruang Lingkup

Saat ini mencakup satu domain:

- **`struktur-pengeluaran/`** — 5 kategori pengeluaran: rutin, tidak rutin, berkala, darurat, dan sosial.

Ke depannya bisa berkembang ke domain lain: pemasukan, investasi, utang, aset, dan sebagainya.

## Prinsip Dasar

1. **Satu transaksi = satu kategori** — tidak ada tumpang tindih.
2. **Dokumentasi sistem, bukan catatan harian** — file ini tempat aturan, bukan tempat mencatat transaksi.
3. **Gerbong, bukan taksonomi akademik** — tujuan akhirnya adalah kecepatan keputusan, bukan kesempurnaan definisi.
